# Planning documents

Store phase-level designs and scoped working proposals here. [The roadmap](../roadmap.md) owns progress; plans describe intended work and do not pass Gates.

Start with [AGENTS.md](../../AGENTS.md), current BOOT routing, and the affected system owner. Keep a plan finite: outcome, confirmed requirements, scoped assumptions, actual starting state, responsibilities, work order, risks, acceptance evidence and deferrals. Link shared contracts instead of copying them.
