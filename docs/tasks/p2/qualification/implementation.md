### Implementation

- Godot 4.7.2 `--help` exposes `--rendering-method <renderer>` and `--scene <path>`. `tools/dev compare compatibility` maps to `gl_compatibility`; `tools/dev compare forward-plus` maps to `forward_plus`. Both launch `res://scenes/renderer_comparison.tscn`, which instances the exact P1 `main.tscn`. The override is process-local; tracked `game/project.godot` remains `gl_compatibility`. `--effects=off` is an optional diagnostic argument.
- `RendererComparison.cs` adds presentation after P1 main and `StarterWorld` finish initialization. The P1 sand floor, Fish3 player, camera, course, rock, coral, display and UI stay in place. The bounded extension adds one Rock Face 02 and one Acropora palmata, fog/distance color, existing top directional light, animated caustic overlay and 24 CPU motes. Forward+ alone loads a screen-copy tint shader on CanvasLayer 0, below P1 help and pause UI. Compatibility does not load this resource. The slice is diagnostic; normal play still uses `main.tscn`.
- The check mode loads and instantiates all seven added P2 mesh packages, loads all 15 Ground060/Gravel041/Rock063 maps, checks three Poly Haven binary dependencies and loads their nine texture maps. P1 main separately checks Fish3, Coast Sand 01, Rock Face 01 and Heliopora. These source files reside in ignored `vendor-local` storage and match the local inventory; the comparison scene does not place the full prepared palette.
- Effect toggling changes only fog and presentation visibility. A focused runtime assertion checks fish position, velocity and tuning identity, camera identity, one fish and one camera, finite/bounded shader and fog values, the mote count, and UI layer order. It does not replace a moving-frame native test.

## P2 P5 — Underwater atmosphere

Date: 2026-11-09. Starting checkout: clean `main` at `312d05f`, root `0.2.4`, saved `forward_plus` renderer. The owner-selected [Forward+ decision](renderer-decision.md) remains unchanged. ### Implementation and tuning boundary

- `UnderwaterAtmosphere.cs`, attached to one `UnderwaterAtmosphere` node in normal `main.tscn`, owns P2 environment, light, projected caustics, GPU motes and screen treatment. `P2HabitatWorld` no longer assigns a second environment. P1 `p1_course_fixture.tscn`, fish motor, input, camera and `swim_tuning.tres` are unchanged. The component reads no fish or camera state and writes no authoritative state. It refuses non-Forward+ initialization; no Compatibility production branch was built.
- The runtime `WorldEnvironment` uses a blue-green background `(0.035, 0.17, 0.22)`, color ambient `(0.56, 0.73, 0.76)` at energy `0.42`, exponential distance fog density `0.0035`, lower-water height fog density `0.018` below height `-1`, and Forward+ volumetric fog density `0.024`, length `64 m`, albedo `(0.40, 0.72, 0.76)`, ambient inject `0.34` and anisotropy `0.18`. A top-biased directional light is rotated `(-1.05, -0.48, 0)` radians, with energy `1.25` and color `(0.78, 0.92, 0.90)`. These colors preserve the visible P4 sand/gravel/rock/coral differences and Fish3 orange at the sampled spawn view; P7 must judge the complete routes.
- One Forward+ `Decal` projects a generated 256² patterned emission/albedo mask through an `84 × 24 × 84 m` world volume. It covers the four seabed zones and placed rock/coral surfaces without replacing their imported materials. Default color is `(0.68, 0.88, 0.78)`, emission energy `0.45`; slow world-space translation/rotation uses a `0.10` drift rate and stops with tree pause. An initial four-projector version produced a visible center join in a rendered difference view; the single bounded projector removed that join. RGB now carries the line pattern as well as alpha, since alpha-only emission gave a broad wash on the software renderer.
- One world-anchored `GpuParticles3D` system emits at most `128` motes over an approximately `54 × 11 × 54 m` box, with `18 s` lifetime, upward velocity `0.012–0.045 m/s`, translucent color `(0.73, 0.91, 0.82, 0.33)`, small unshaded sphere draw pass and explicit `56 × 14 × 56 m` visibility bounds. It is not camera attached. P6 can add a distinct fish-local wake without reusing this environmental emitter.
- `underwater_screen.gdshader` samples the screen at a maximum `0.55` pixel wave displacement with `0.007` color variation. It is a restrained screen treatment; water depth comes from the environment fog rather than a second depth-texture pass. The screen `CanvasLayer` is layer `0`, has an input-ignoring full-viewport rect that responds to size changes, and sits below help/pause/settings layers at `10`. If the optional shader is absent, the component warns and keeps the fog/light/caustic/mote stack alive. Shader `TIME` continues behind the paused UI; the world-anchored caustic motion pauses. No ocean surface is simulated.
- P7 tuning controls are centralized as exported component fields for water/ambient/fog/sun/caustic/mote colors, fog densities, start height and length, ambient injection/anisotropy, sun angle/energy, caustic energy/drift, mote count/lifetime, screen warp/variation and optional shader path. Finite ranges are checked at startup. `SetEnabled` is a Forward+ diagnostic toggle for presentation equality checks. P6 can read the existing `FishController.PresentationSpeed`, `PresentationEffort`, `PresentationTurn` and velocity without sending forces or time back to the motor.
