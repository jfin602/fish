# C3 R1/M2 terrain-conditioned geology — 2026-11-11

**State:** implemented and reviewed far enough to start M3 at root `0.3.6`. This is a manual progression handoff, not final world acceptance. The historical [P7 failure](../closeout.md) remains in force; no Base World was promoted and M3 was not run as part of this task.

## Implemented world

The finished M1 terrain now supplies deterministic geology sites. Candidate scoring uses shoreline distance, water depth, slope, ridge/shoulder mass and separation from other features. When the selected site needs more surrounding mass, the basin adds connected shoulders while keeping the passage center open. Seed-specific curved centerlines and bounded changes in width, roof, wall asymmetry and floor height replace fixed world-coordinate shells. The five resulting features remain actual generated mesh and collision. Their structural material shares the seabed surface language, with terrain, rock and rubble accents distributed along both banks and outward from the mouths. These accents do not add collision to the protected opening.

The new world package is `c3-full-8`; historical `c3-full-3` M1 candidates and `c3-full-1` Base Worlds retain their compatible load paths. Normal play in the expanded basin now uses expanded fish limits; the P1 fixture and historical Base World retain their previous limits.
