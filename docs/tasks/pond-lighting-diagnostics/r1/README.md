## Owner screenshot follow-up — hard local shade edge

The owner's `banding.png` shows a dark polygonal patch on the near sediment, distinct from the broad distance-fog transition. The first follow-up changed only filter blur (`6`) and opacity (`0.6`), but the owner still saw the edge. That trial is rejected. A closer fixed-scene replay moved the Bluegill to `(-38, terrain height + 2, 4)`, facing 23° at 14:00; its left log casts the same jagged ground silhouette. Turning off the Sun shadow removes that patch. The [matched native crop](comparison/owner-ground-fade.png) compares the rejected setting with the revised one at the same pose and time.

The revised Pond Sun uses `LightAngularDistance = 4°`, `ShadowBlur = 3`, and full shadow opacity. Angular softness creates a wide **fade** from the log's shade into lit sediment while preserving a shaded side under cover. It keeps the existing one-map Sun shadow, with no extra light or screen pass. It does not change the original R1 fog parameters or the Ocean profile. The owner's exact camera position and solar time were not available; the replay matches the distinctive left-log shadow shape rather than claiming an identical owner frame.

At this 1920×1200 Forward+ pose with VSync off, 90 sampled CPU frame intervals measured the rejected blur/opacity setting at **4.90 ms median** and the revised angular setting at **8.61 ms median**; both used 244 draws and 296,874 primitives. A second bounded sequence measured 5.05 ms for the rejected setting and 8.45 ms on repeat for the revised setting. This is a material rendering cost increase on this AMD/Linux host; it is not GPU-only timing or an in-play frame-rate guarantee. A 2° trial cost less (6.51 ms) but left more of the shadow shape recognizable. `tools/dev build`, `inspect-pond-atmosphere`, and `inspect-solar-lighting` passed. Full native captures and manifests are in ignored `artifacts/pond-lighting-diagnostics/r1/edge-variants-14b/`, `edge-verified-14/`, and `edge-cost-14/`. Owner free-swim visual qualification remains open, and this follow-up does not advance a Gate or package version.
