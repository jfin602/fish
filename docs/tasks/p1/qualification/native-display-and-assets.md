## Commands and boundaries

The `tools/dev` composition was inspected before project checks. `doctor` is read-only; `run` composes import/build first; `build` performs only the affected .NET build. To avoid repeating unchanged import and build stages, the qualified equivalent independent launch path used the pinned command from `tools/local.env`, for example:

```bash
./tools/dev doctor
./tools/dev build
source tools/local.env
XDG_DATA_HOME="$PWD/artifacts/p5/profile-fresh" "${GODOT_CMD[@]}" --path "$PWD/game"
XDG_DATA_HOME="$PWD/artifacts/p5/profile-fresh" "${GODOT_CMD[@]}" --path "$PWD/game" -- --display-mode=fullscreen
XDG_DATA_HOME="$PWD/artifacts/p5/profile-fresh" "${GODOT_CMD[@]}" --path "$PWD/game" -- --display-mode=windowed-fullscreen
XDG_DATA_HOME="$PWD/artifacts/p5/profile-fresh" "${GODOT_CMD[@]}" --path "$PWD/game" --script "$PWD/artifacts/p5/perf_probe.gd" --rendering-method gl_compatibility
XDG_DATA_HOME="$PWD/artifacts/p5/profile-fresh" "${GODOT_CMD[@]}" --path "$PWD/game" --script "$PWD/artifacts/p5/collision_probe.gd" --rendering-method gl_compatibility
wmctrl -lG
xwininfo -id "$fish_window_id"
xprop -id "$fish_window_id" _NET_WM_STATE _NET_FRAME_EXTENTS
xrandr --output eDP --mode 1280x800
xrandr --output eDP --mode 1920x1200
sha256sum game/assets/vendor-local/heliopora-coerulea.glb artifacts/assets/source/heliopora-coerulea/usnm_1145291-100k-2048_std.glb
git diff --check
```

`fish_window_id` was the Fish (DEBUG) X11 window identifier obtained from `wmctrl -lG`; it varied by launch. For the reversible negative case, the local `game/assets/vendor-local/heliopora-coerulea.glb` was moved to ignored `artifacts/p5/heliopora-coerulea.glb.disabled`, the game was launched and quit, and the file was moved back before SHA-256/readiness checks. The interactive mode changes, Alt-Tab, keyboard/menu actions and screenshots used real X11 input and `gnome-screenshot` against the independent Fish window. A local ignored `artifacts/p5/perf_probe.gd` instantiated `res://scenes/main.tscn` in a native Compatibility-renderer process and sampled `Engine.get_frames_per_second()` and Godot `Performance` monitors once per second; `artifacts/p5/collision_probe.gd` performed the two bounded physics traversals. Both ended with exit 0 and `FISH_STARTER_WORLD_READY`; these probes did not create tracked game code. A post-repair Godot MCP editor play, with exact Fish peer verified, returned the populated live scene tree and two clean startup messages. Editor play is supporting resource/state evidence only; native window captures above establish display and pixels.
