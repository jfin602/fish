# FAF Blender tooling

Source-controlled Python foundations for original Fish assets. Add this `blender/` directory to Blender's Python path, then import `common.naming`, `common.palette`, `common.validation` or `common.export`. Blender MCP may call these modules from a controlled session; durable construction logic belongs here, not in a one-time console command. The `fish/` package contains the first asset's shared rigging and wave animation helpers, plus a species-specific Yellow Tang adaptation recipe. The `rocks/` package now contains the deterministic [FAF-ROCK-001](../../docs/fish-asset-factory/rock-001/README.md) boulder generator and family recipe. The `coral/`, `plants/` and `terrain/` packages remain reserved for generators proven by actual reviewed assets.

The helpers provide canonical names, starter palette swatches, basic selected-object checks and a guarded selected-object GLB export constrained to the active Blender scene. The export helper refuses an existing output unless `overwrite=True` is passed deliberately. `fish.rig` and `fish.animation` expose reusable deform-rig and body-wave methods; `fish.yellow_tang_001` applies reviewed Yellow Tang-specific stations and amplitudes to a copied prototype. `rocks.boulder.BoulderSpec` exposes metre scale, footprint, mass, facet, contact and lean controls with a deterministic seed; `rocks.build_001` records the first four variants and can build a Blender master plus four selected-object GLBs. They do **not** allocate IDs, prove visual quality or certify a Godot import. See the [FAF-FISH-001 record](../../docs/fish-asset-factory/fish-001/README.md), [FAF-ROCK-001 record](../../docs/fish-asset-factory/rock-001/README.md) and [export contract](../../docs/fish-asset-factory/blender-godot-contract.md).

Run focused checks from the repository root with `PYTHONPATH=tools/asset-factory/blender python3 -c 'from common import naming, palette, validation, export'`. Export needs Blender's `bpy`; importing the module does not.
