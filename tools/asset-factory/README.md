# FAF Blender tooling

Source-controlled Python foundations for original Fish assets. Add this `blender/` directory to Blender's Python path, then import `common.naming`, `common.palette`, `common.validation` or `common.export`. Blender MCP may call these modules from a controlled session; durable construction logic belongs here, not in a one-time console command. The `fish/` package contains shared rigging and wave animation helpers, a species-specific Yellow Tang adaptation recipe, and four new distinct [reef-fish blueprints](../../docs/fish-asset-factory/reef-fish-pack-001/README.md). The `rocks/` package contains the deterministic [FAF-ROCK-001](../../docs/fish-asset-factory/rock-001/README.md) boulder generator and family recipe. The `coral/` package contains four deterministic [FAF-CORAL-001–004](../../docs/fish-asset-factory/coral-pack-001/README.md) family generators and a twelve-variant recipe. The `plants/` package contains three deterministic [FAF-PLANT-001–003](../../docs/fish-asset-factory/plant-pack-001/README.md) vegetation generators and an eight-variant recipe. The `terrain/` package contains the reviewed [FAF-TERRAIN-001](../../docs/fish-asset-factory/terrain-001/README.md) chunk builder.

The helpers provide canonical names, starter palette swatches, basic selected-object checks and a guarded selected-object GLB export constrained to the active Blender scene. The export helper refuses an existing output unless `overwrite=True` is passed deliberately. `fish.rig` and `fish.animation` expose reusable deform-rig and body-wave methods; `fish.yellow_tang_001` applies reviewed Yellow Tang-specific stations and amplitudes to a copied prototype. `rocks.boulder.BoulderSpec` exposes metre scale, footprint, mass, facet, contact and lean controls with a deterministic seed; `rocks.build_001` records the first four variants and can build a Blender master plus four selected-object GLBs. `coral.families` exposes four form-specific specs and generators, while `plants.families` exposes three form-specific vegetation specs and generators with UV height coordinates reserved for later sway. The corresponding pack recipes build editable masters, manifests and separate GLBs. These modules do **not** allocate IDs, prove visual quality or certify a Godot import. See the [FAF-FISH-001 record](../../docs/fish-asset-factory/fish-001/README.md), [FAF-ROCK-001 record](../../docs/fish-asset-factory/rock-001/README.md), [coral pack record](../../docs/fish-asset-factory/coral-pack-001/README.md), [vegetation pack record](../../docs/fish-asset-factory/plant-pack-001/README.md) and [export contract](../../docs/fish-asset-factory/blender-godot-contract.md).

Run focused checks from the repository root with `PYTHONPATH=tools/asset-factory/blender python3 -c 'from common import naming, palette, validation, export'`. Export needs Blender's `bpy`; importing the module does not. Rebuild FAF-FISH-002–005 from a clean Blender process with `blender -b --python tools/asset-factory/blender/fish/build_reef_pack_001.py -- --root "$PWD" --overwrite` only when intentionally replacing the pack's own generated outputs.

Fish generation now requires a declared breathing anatomy. The reusable `fish.breathing` module creates paired operculum deform bones and localized bilateral weights for ordinary bony fish, checks their neutral pose and exported GLB joints, and records exposed-gill species as explicitly pending until a real slit mechanism exists. `fish.reef_families.create_fish` invokes these steps automatically; `fish.yellow_tang_001` uses the same helpers with its original sculpt coordinates. Run the focused contract check with `blender -b -t 2 --python tools/asset-factory/blender/fish/check_breathing.py -- --root "$PWD"`. The check exercises independent poses, existing Actions, exported skeletons and missing-component rejection without saving assets.

The `details/` package adds four small deterministic shell, rubble, pebble and sponge construction APIs plus an eight-piece [reef-floor detail recipe](../../docs/fish-asset-factory/detail-pack-001/README.md). Each output is one static mesh and one material; the editable master keeps linked review copies outside each selected GLB export. Rebuild only the pack's own generated files with `blender -b --python tools/asset-factory/blender/details/build_pack_001.py -- --root "$PWD" --overwrite`.

The [fish life-stage builder](blender/fish/build_life_stages.py) creates 20 non-adult representations from five existing fish identities. [`fish.life_stages`](blender/fish/life_stages.py) owns stage proportions, palettes and motion settings; species geometry remains in the existing fish family tooling. Its shark stages add a localized exposed-slit deformation rig while the preserved canonical adult remains pending. From the repo root, build intentionally with `blender -b -t 2 --python tools/asset-factory/blender/fish/build_life_stages.py -- --root "$PWD" --overwrite`; then run [`check_life_stages.py`](blender/fish/check_life_stages.py), [`check_life_stage_deformation.py`](blender/fish/check_life_stage_deformation.py), and [`configure_life_stage_imports.py`](blender/fish/configure_life_stage_imports.py) with their documented arguments. The separate review builder and renderer produce lineup evidence without scaling any export.

The original freshwater [Pond fish pack](../../docs/fish-asset-factory/pond-fish-pack-001/README.md) uses [`fish.pond_families`](blender/fish/pond_families.py) for five species-specific station/fin/head/palette recipes, a shared deterministic loft, skin, egg rig, and species/stage wave generation. [`build_pond_pack_001.py`](blender/fish/build_pond_pack_001.py) produces five editable masters and 25 Pond-only GLBs; its guarded `--overwrite` affects only those outputs. [`check_pond_pack_001.py`](blender/fish/check_pond_pack_001.py) checks the exported manifest and GLBs. Open each species master to run [`check_pond_deformation.py`](blender/fish/check_pond_deformation.py) and [`render_pond_pack_001.py`](blender/fish/render_pond_pack_001.py) with `--root "$PWD" --species N`. [`configure_pond_imports.py`](blender/fish/configure_pond_imports.py) sets the 25 Godot import sidecars. The focused [`Godot checker`](../../game/dev/faf_pond_fish_check.gd) compares actual imported dimensions, triangles, materials, bones and clips with the manifest.

The Pond-only [foliage pack](../../docs/fish-asset-factory/pond-foliage-pack-001/README.md) uses [`plants.pond_foliage`](blender/plants/pond_foliage.py) for six distinct deterministic form families. [`build_pond_foliage_001.py`](blender/plants/build_pond_foliage_001.py) saves one editable master, 13 Pond-tagged individual GLBs, and the measured manifest. [`check_pond_foliage_001.py`](blender/plants/check_pond_foliage_001.py) checks binary GLBs and metadata; the [Godot checker](../../game/dev/faf_pond_foliage_check.gd) verifies actual imports. All outputs are under Pond-only asset paths.
